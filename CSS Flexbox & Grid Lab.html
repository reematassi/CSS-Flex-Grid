Lining things up is harder than it looks

Before flexbox, designers pushed boxes around with floats and positioning. Flexbox replaced all of that with one line on the parent.

Big idea
One container decides how its children line up — in one direction.
Essential question
How can we place items in a row or a column and share the space between them, without floats or positioning?

Guiding questions

  1. What is a flex container, and what are flex items?
  2. How do I switch the direction items flow in?
  3. What happens when the items do not fit on one line?
  4. How do I make the same navigation bar work on a laptop and a phone?

One parent, many children

Flexbox is a layout model built on a container. The parent becomes a flex container and every direct child becomes a flex item — the container then distributes space and aligns its items dynamically.

Anatomy

Click a part to see which element it is in the code and on the page.

flex container
The element with display: flex; (or display: inline-flex;). It is the parent of everything you want to arrange.
flex items
The direct children of the container. A grandchild is not a flex item of the same container.
container properties
display, flex-direction, flex-wrap, justify-content — you will meet each one next.

Which way do the items flow? flex-direction

flex-direction sets the direction the container stacks its items. Two values from the slides: row (left to right — the default) and column (top to bottom).

Worked example

Remember: row is the default, so flex-direction: row; only matters when you need to switch back — for example inside a media query.

When items do not fit: flex-wrap

flex-wrap decides whether items may move onto a new line. nowrap (the default) squeezes everything onto one line; wrap lets items flow onto the next line.

Shrink the container

Sharing the space: justify-content and align-items

justify-content aligns the items along the direction of flow — for example center puts them in the middle. align-items aligns them across it.

Alignment explorer

Make sense of it: two axes

Every flex container has a main axis — the direction set by flex-direction — and a cross axis at right angles to it. Every alignment property works on one of the two.

See the axes turn

The flex container properties

PropertyWhat it controlsValues you met

Common mistake: switching to flex-direction: column also turns the axes. Now justify-content works vertically and align-items works horizontally.

Responsive web design

Responsive web design is about creating pages that look good on all devices. The page automatically adjusts to different screen sizes by resizing, hiding, shrinking, enlarging or moving content — using only HTML and CSS.

Step 1 — set the viewport

Add this <meta> tag to the <head> of every page. Without it, a phone pretends to be a wide desktop screen and shrinks the whole page.

Step 2 — responsive images

Two ways to make an image follow its container. Drag the slider to change the space available.

width:100%
The image always fills its container — it scales up and down, and can become blurry when stretched.
max-width:100%
The image scales down if it has to, but never grows larger than its original size. Add height:auto to keep its shape.

Different styles for different screens: @media

A media query wraps CSS rules that only apply when a condition is true — for example when the screen is 700 pixels wide or less. Together with flexbox, it turns a row of links into a column on a phone.

Summary

  • Flexbox is a layout model that distributes space and aligns content inside a container, even when the size of the items is unknown or dynamic.
  • The parent with display:flex is the flex container; its direct children are the flex items.
  • Container properties: display, flex-direction, flex-wrap, justify-content (and align-items).
  • Responsive design uses the viewport tag, responsive images and media queries to look good on any screen.

Rows and columns at the same time

Think of a shop shelf, an egg box or a big table: everything sits in rows and columns that line up. CSS Grid gives a web page the same structure.

Big idea
A grid places content into rows and columns that line up in two directions.
Essential question
How can we arrange page content into rows and columns — and re-arrange them for a smaller screen?

Guiding questions

  3. What is an fr?

display: grid and grid-template-columns

An element becomes a grid container when its display is grid. grid-template-columns then lists the columns — one value per column, separated by spaces. Rows are created automatically, as many as needed.

Column builder

Worked example — four equal columns

Four values means four columns. All four are 1fr, so they are equal.

Fractions of the space: the fr unit

fr stands for fractional unit. The browser adds up all the fr values and gives each column its share. 1fr 4fr makes 5 parts in total: the first column gets 1 part, the second gets 4.

Share the width

Space between cells: gap

The gap property (also written grid-gap) sets the size of the space between the rows and the columns. It never adds space around the outside edge — that is padding's job.

Grid anatomy

Grid or table?

A grid looks like a table, but it is a layout tool: the HTML stays a simple list of boxes, and CSS decides how many columns there are. Change one line of CSS and the same HTML becomes two columns, or one. A <table> is for data — its rows and columns are fixed in the HTML.

Summary

  • CSS Grid creates a grid-like, two-dimensional structure of rows and columns on a web page.
  • display:grid makes a grid container; grid-template-columns sets the number and width of the columns.
  • fr is a fraction of the available space; gap is the space between rows and columns.
  • A media query that changes grid-template-columns makes the grid responsive.
